# Data

The repository uses two kinds of inputs: synthetic study files committed under `data/`, and the public TruthfulQA dataset used by Phase B.

## Synthetic inputs

The CSV files under `data/` contain constructed prompts and templates created for the computational experiments. They do not contain patient data, private organizational records, credentials, or production logs. Strings that resemble sensitive values are fictitious examples used to exercise the study code.

## TruthfulQA

Phase B loads the public `truthfulqa/truthful_qa` dataset, configuration `generation`, split `validation`, through the Hugging Face `datasets` interface. TruthfulQA is not redistributed in this repository.

## Canonical numerical outputs

The files directly under `results/` are the canonical numerical summaries used by the study. Phase D can be regenerated by running:

```bash
python experiments/phase_d_sensitivity.py
```

Regenerated Phase D outputs are written under `results/generated/`, which is excluded from version control. The canonical committed summaries remain unchanged unless a verified analysis update is intentionally released.

## Data provenance

`REPRODUCIBILITY.md` records the source, split rules, seeds, thresholds, and canonical output for each computational phase. `configs/reproducibility.yaml` provides the corresponding machine-readable configuration.
